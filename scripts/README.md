# سكربتات قاعدة البيانات — UniBookClub

## للمشروع الجديد (استخدم هذا)

```
scripts/fresh/
├── README.md          ← ابدأ من هنا (دليل عربي كامل)
├── 01_install.sql     ← الجداول + الفهارس + RLS
├── 02_functions.sql   ← الحجز، النقاط، الأدمن
├── 03_seed.sql        ← الكليات والتخصصات
├── 04_storage.sql     ← bucket الصور
└── 05_admin_setup.sql ← ترقية المدير (عدّل البريد أولاً)
```
